## 🛠️ How these are made

- **Spec first:** I write a detailed brief covering scope, accuracy rules and what must not be confused.
- **Build with AI:** an AI assistant drafts the poster, notes or code.
- **Question and refine:** I push back, ask "why?" and revise until each piece holds up.
- **Illustrative values are labelled:** example numbers are marked as such, not taken from any specific model.

If you spot a technical mistake, please [open an issue](../../issues). Corrections are part of the learning.
